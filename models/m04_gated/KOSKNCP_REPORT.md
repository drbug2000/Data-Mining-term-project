# KoSKNCP 설명서 — SKNCP 중심 모델 (직관 + Task1/Task2 실측)

SKNCP(의미적 k-최근접 클릭예측)를 핵심으로 한 모델. 학습 content head 대신 **비모수 협업필터
신호**를 쓴다. 코드: `experiments/exp_koskncp.py`. 용어(실측 F1/상한 F1)는 `UNIFIED_REPORT §0`.

**실측 결과**: Task1(클릭예측) 실측 F1 ≈ **0.0931** (AUC 0.703) · Task2(광고추천) NDCG@3 ≈
**0.099** (의미 cosine 기준; SKNCP 자체는 Task2 에 약함 — §7).

---

## 1. 한 줄 요약

> "**나와 비슷한 검색을 한 사람들이 실제로 클릭한 광고와, 지금 이 광고가 얼마나 비슷한가**(SKNCP)
> 를 핵심 신호로, 신뢰 클릭률들과 함께 로그-오즈로 합쳐 클릭을 예측한다."

m04(권장모델)이 검색어↔광고를 **학습한** content head 로 매칭한다면, KoSKNCP 는 **학습 없이**
"비슷한 검색의 클릭 광고들"이라는 **이웃의 집단 행동**으로 매칭한다(협업필터).

## 1.5 왜 SKNCP 인가 — EDA 로 전제 검증

| # | 설계 전제 | **EDA 측정 근거** | 방법 반영 |
|---|---|---|---|
| 1 | 극단 불균형 → 랭킹 최상단 문제 | 클릭률 **1.11%** (외부 229/20,000) | F1 직접 최대화 좌표상승(log-loss 아님) |
| 2 | 처음 보는 세션 → 일반화 신호 필요 | SearchID 겹침 **0.01%**, 미관측 유저 **29%** | 세션 무관 신호(엔티티 CTR) + SKNCP(검색어 임베딩 기반, 라벨 무관) |
| 3 | **직접 텍스트 유사도 무의미** → 그러나 "이웃의 클릭"은 강함 | raw cosine **AUC 0.530**(d 0.10) vs **SKNCP AUC 0.593**(d 0.44, 약 11배 강) | 직접 유사도 대신 **SKNCP**(이웃 클릭 광고와의 max 유사도) |
| 4 | HistCTR 강하나 희소 불안정 | 구간별 CTR **0.6%→7.6%** 단조↑, AUC 0.670 | log(HistCTR) 사전 + Laplace 평활 |
| 5 | 위치 편향 | Position 1 **1.29%** vs 7 **0.71%** | **IPS 위치보정 항** `log(위치CTR/전역)` (m04 와 달리 명시) |
| 6 | 로그인 약신호 | 비로그인 1.20% vs 로그인 0.99% (비율 1.21) | 비로그인 고정 offset |
| 7 | 검색당 1~2 광고 | 1개 57%, 2개 43% | 검색 내 순위 항(저가중 보조) |

**전제 3 이 SKNCP 의 존재 이유**: "아디다스 러닝화" 검색자가 "ASICS"를 클릭하면 텍스트
유사도는 낮지만(AUC 0.530, 거의 동전던지기) **클릭 의도**는 분명하다. SKNCP 는 텍스트가 아니라
"비슷한 검색에서 실제 클릭된 광고" 를 기준 삼아 이 의도를 포착한다(d 0.04→0.44, 11배). 단,
이건 **클릭이 일어난 광고에만** 적용되므로 Task2(전체광고 랭킹)에는 부적합(§7).

## 2. SKNCP — 핵심 아이디어 (가장 중요)

직접 "검색어 텍스트 ↔ 광고 텍스트" 코사인은 거의 무의미하다(AUC 0.518). 클릭은 텍스트가
비슷해서가 아니라 **사람들이 실제로 원해서** 일어나기 때문.

```
SKNCP(검색어 q, 광고 a):
  1. q 와 가장 비슷한 학습 검색어 K=100개를 찾는다 (검색어 임베딩 코사인)
  2. 그 100개 검색에서 실제 클릭된 광고들을 모은다  (= 이웃의 클릭 집합)
  3. 그 클릭 광고들과 현재 광고 a 의 최대 코사인 유사도를 점수로
```
- 직관: "아디다스 러닝화"를 검색한 사람들이 실제 "ASICS GT-2000"을 클릭했다면, 텍스트
  유사도는 낮아도 SKNCP 는 높다 → **클릭 의도**를 포착.
- 효과: 직접 의미유사도(Cohen's d 0.04) 대비 **11배 강한 신호(Cohen's d 0.44)**, 단독 AUC 0.593.
- 한계: 학습에서 **클릭된 적 있는 광고**만 이웃에 들어옴(~1,759개) → 커버리지 67%, 나머지는 0.

## 3. Task1 점수 = 9항 로그-오즈

```
점수 = σ(  w1·log HistCTR + w2·log ad_ctr + w3·log ip_ctr + w4·log dev_ctr + w5·log cat_ctr
         + (비로그인 +0.53)                      ← 고정
         + w6·위치보정(IPS) + w7·검색내 순위
         + w8·SKNCP + w9·이웃광고 CTR )
```
- **5개 신뢰 CTR**: 과거 클릭률(HistCTR/광고/IP/기기/카테고리), Laplace 평활. (m04 와 동일)
- **위치보정(IPS)**: 상단 광고가 더 잘 보이는 편향 제거 → 순수 품질. `log(위치CTR/전역)`.
- **검색 내 순위**: 같은 검색의 광고들 중 HistCTR 상대순위(1등 +, 꼴찌 −).
- **SKNCP**: §2 의 협업필터 신호 (핵심).
- **이웃광고 CTR**: 광고 품질의 상대적 logit.

## 4. 가중치는 어떻게 — 좌표상승(F1 직접 최대화) + w_min=0.5

- m04 와 동일하게 **F1 을 직접 최대화**하는 좌표상승(한 번에 가중치 하나씩 격자 탐색).
- KoSKNCP 특유: **w_min=0.5 정규화** — 모든 가중치 ≥0.5 강제 → HistCTR 같은 강신호를 좌표상승이
  0으로 죽이는 과적합 방지(안정적 일반화).

**실제 학습된 Task1 가중치** (sorted 80/20):

| 신호 | 가중치 | 해석 |
|---|---:|---|
| **SKNCP** | **3.0** | 가장 높게 채택 — 협업필터 신호가 핵심 |
| **dev_ctr** | **3.0** | 기기별 성향 강함 |
| HistCTR | 2.5 | 강한 사전 |
| ip_ctr | 2.0 | IP 성향 |
| IPS(위치) | 2.0 | 위치 편향 보정 |
| rank, nbr | 1.0 | 보조 |
| ad_ctr, cat_ctr | 0.5 | 하한(중복 신호, 정규화로 0 방지) |

→ 좌표상승이 **SKNCP 를 최상위 가중치로 자동 선택** = KoSKNCP 의 핵심 주장 입증.

### 4.5 방법론 명세 (재현 정확값)

**(A) SKNCP 계산** — `exp_koskncp.py`
```
인덱스 : 클릭(y=1) 학습 행 → (검색어 임베딩, 그 클릭 광고 임베딩) 쌍 모음
         내부검증용 = 내부학습 클릭 / 외부·Task2용 = 전체학습 클릭 (leak 방지)
점수   : 1) 현재 검색어와 인덱스 검색어들의 코사인 상위 K=100
         2) 그 100개의 클릭 광고 임베딩을 모음 (세션당 cap, 전체 cap 300)
         3) SKNCP = max cos(현재 광고, 모은 클릭광고들)
구현   : 임베딩 L2정규화 후 내적, GPU 배치(512) topk. 빈 이웃 → 0 (미커버 33%)
설계근거: K=100 이 Cohen's d 최대(K작으면 커버↓, K크면 노이즈↑); max 집계가 mean(0.31)보다 강함(0.44)
```

**(B) Task1 9항 좌표상승** — F1 직접 최대화 + **w_min=0.5 정규화**
```
점수 = Σ wⱼ·featⱼ + log(1.7)·[비로그인]
탐색 = w=[1..1] → 각 wⱼ 를 {0.5,1.0,...,3.0} 격자(하한 0.5!)로 훑어 내부검증 F1 최고값 고정
       w_min=0.5 = HistCTR 같은 강신호를 좌표상승이 0으로 죽이는 과적합 방지(KoSKNCP 핵심)
CTR  = Laplace 평활 k=20 (내부검증=내부학습 카운트 / 외부=전체학습 카운트)
임계값 = 내부검증 5-겹 OOF 비율 평균 (외부 정답 미사용)
분할 = SearchID 정렬 80/20
```

**(C) Task2 랭킹**: 각 검색쿼리 → 전체 후보광고(17,518)에 대해 SKNCP(전체학습 인덱스) +
α·log(ad_ctr) 또는 의미 cosine 으로 점수 → 내림차순 랭킹 → NDCG@3.

## 7. Task2 성능 (광고추천, NDCG@3) — 외부 ad_validation 214쿼리

각 검색쿼리에 대해 전체 후보광고 17,518개를 랭킹해 정답 광고의 순위로 NDCG@3.

| 랭킹 점수 | NDCG@3 |
|---|---:|
| SKNCP 단독 | 0.0140 |
| SKNCP + ad_ctr 사전 | 0.0434 |
| **의미 cosine (검색어-광고 임베딩)** | **0.0989** |

**핵심 발견**: **SKNCP 는 Task2(검색→전체광고 랭킹)에 약하다.** 이유 = SKNCP 는 학습에서
**클릭된 적 있는 광고(~1,759개)만** 이웃에 포함 → 17,518개 후보 대부분이 0점이라 정렬 불가.
반면 광고추천은 **모든 광고에 점수가 필요한 retrieval** 문제라, 텍스트 의미 cosine 이 훨씬 낫다.

→ **SKNCP 는 클릭예측(Task1) 전용 신호**, 추천(Task2)에는 의미 임베딩 매칭이 적합. Task 별로
필요한 신호가 다름을 보여준다.

## 8. 정직성(leak-free)
- Task1 의 모든 선택(가중치·임계값)은 학습 sorted 80/20 내부 분할에서만.
- SKNCP 이웃 인덱스: 내부검증용=내부학습 클릭 / 외부·Task2용=전체학습 클릭.
- CTR: 내부검증=내부학습 카운트 / 외부=전체학습 카운트.
- 외부 정답(click/ad_validation_answer)은 **최종 F1/NDCG 채점에만**.

## 10. m04(권장) vs KoSKNCP 한눈에

| | m04 (content-ensemble) | KoSKNCP (SKNCP) |
|---|---|---|
| 의미 신호 | **학습** bi-encoder head (AUC 0.684) | **비학습** SKNCP 협업필터 (AUC 0.593) |

| Task1 AUC | **0.7133** | 0.7029 |

**결론**: Task1 에선 두 방법 통계적 동등(m04 가 AUC 약간 우위). Task2 에선 둘 다 SKNCP/협업필터가
아니라 **의미 임베딩 cosine** 이 답. 천장(Task1 실측 ~0.10)은 정보량 한계로 양쪽 공통.
